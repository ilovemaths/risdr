# Weighted sparse directions from dense SDR directions

Weighted sparse directions from dense SDR directions

## Usage

``` r
weighted_sparsify_directions(V, lambda, weights = NULL, tol = 1e-10)
```

## Arguments

- V:

  Dense direction matrix.

- lambda:

  Non-negative tuning parameter.

- weights:

  Variable-level penalty weights.

- tol:

  Numerical tolerance.

## Value

Sparse direction matrix.
