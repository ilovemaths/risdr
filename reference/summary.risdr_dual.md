# Summary method for dual RISDR objects

Summary method for dual RISDR objects

## Usage

``` r
# S3 method for class 'risdr_dual'
summary(object, top_n = 20L, ...)
```

## Arguments

- object:

  Object of class `risdr_dual`.

- top_n:

  Number of selected variables to print.

- ...:

  Additional arguments passed to internal methods.
