# Weighted soft-threshold operator

Weighted soft-threshold operator

## Usage

``` r
weighted_soft_threshold(z, lambda, weights = NULL, tol = 1e-10)
```

## Arguments

- z:

  Numeric vector.

- lambda:

  Non-negative tuning parameter.

- weights:

  Penalty weights.

- tol:

  Numerical tolerance.

## Value

Thresholded vector.
